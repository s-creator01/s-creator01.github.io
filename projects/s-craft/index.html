S-Craft Tools.

Free browser-based PDF, image, text, video, audio, time, and number utilities.

Made to be useful.

S-Craft Tools brings everyday file and utility tools together in one browser-based workspace. Choose a tool, add a file when needed, adjust its options, and save the result.

Visit website ↗View source ↗

Explore the features

PDF tools

Merge, split, compress, organize and rotate pages, add watermarks, add or remove a known PDF password, convert images and PDFs, and add a visible signature.

Image tools

Resize, crop, compress and convert images; add text or watermarks; rotate, combine or sign images; and remove metadata.

Video and audio

Trim, compress, convert and adjust media. Video tools include crop, resize, rotation, speed, merging and audio extraction; audio tools include volume, fades, looping and noise reduction.

Text, time and numbers

Count and clean text, compare versions, use timers and date tools, or work with percentages, units, estimates, statistics and number conversions. Currency conversion uses a rate you provide.

A workspace that remembers

Browse or search the collection, save favorite tools, and use Quick Access and Recent Activity to return to your work. These preferences are stored in your browser.

On-device processing

The tools are designed to process files on your device. Browser media tools load a processing engine when needed; large or complex files can be limited by the browser and device. The full privacy review is ongoing.

Open source

The public source is available on GitHub. Project-owned code is licensed under AGPL-3.0-only; third-party components have their own notices and licenses.
